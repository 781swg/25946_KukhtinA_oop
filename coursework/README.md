# Курсовая: «Симулятор работы банкомата»

## Реализовано

Основные классы

- `Account`: приватные PIN и баланс, проверка PIN, константный геттер баланса.
- `ATM`: содержит счёт, кассеты купюр и историю операций; управляет картой,
  авторизацией, внесением и снятием денег.
- `Card`: учебная карта с номером счёта `0001`, без хранения PIN.
- `CashCassette`: номинал и количество купюр в одной кассете.
- `Operation`: тип операции, сумма, результат и пояснение.

Один учебный счёт: PIN `1234`, баланс 1000 рублей. Баланс хранится целым
числом рублей. PIN задан в коде открытым текстом только для демонстрации;
реальные карты, деньги и банковские сервисы не используются.
После трёх неверных PIN доступ блокируется до перезапуска программы.
Возврат и повторная вставка карты не сбрасывают ошибки. Правильный PIN
до блокировки сбрасывает счётчик неверных попыток.

При запуске в банкомате 10 000 рублей: 20 купюр по 100, 10 по 500 и 3 по 1000.
Данные и история хранятся только до завершения программы. Несколько клиентов
и сохранение в файл пока не реализованы. Графика — отдельный статический макет;
все операции ниже доступны в консольной версии.

1. **Внесение денег:** приём суммы и увеличение баланса счёта после
   подтверждения операции.
2. **Снятие денег:** выдача суммы и уменьшение баланса только при успешной
   операции.
3. **Проверка операций:** запрет нулевых и отрицательных сумм, проверка
   остатка на счёте и наличных в банкомате. При отказе баланс не меняется.
4. **Повторные попытки ввода PIN:** ограничение числа ошибок и блокировка
   доступа после превышения лимита.
5. **Работа с купюрами:** учёт номиналов и количества купюр, подбор купюр
   для выдачи, отказ, если нужную сумму невозможно выдать.
6. **Работа с картой и сеансом:** вставка и возврат учебной карты,
   отмена операции и завершение обслуживания.
7. **История операций:** запись внесений и снятий с суммой и результатом.

При внесении указывается количество купюр каждого номинала. Сумма
рассчитывается автоматически. При снятии сначала подбирается точный набор
доступных купюр; при невозможности выдачи деньги не списываются.
Подтверждение — `y`, другой ответ отменяет операцию. Успехи, отказы
и отмены записываются в историю, включая причину отказа. Ввод, который
невозможно разобрать как целое число, отклоняется ещё в меню, без записи
операции. При возврате карты история и деньги сохраняются в памяти,
но для нового доступа снова нужен PIN.

## Функции в разработке

1. **Работающий графический интерфейс:** ввод PIN и суммы, кнопки внесения,
   снятия и просмотра баланса, сообщения об успехе и ошибках. Подключение
   интерфейса к C++-логике банкомата.
2. **Сохранение в файл:** восстановление баланса, наличных банкомата
   и истории после перезапуска программы.
3. **Несколько клиентов:** выбор счёта по учебной карте, отдельные PIN,
    балансы и истории операций.
4. **Перетаскивание карты и купюр мышкой:** внесение купюр в приёмник,
    получение выданных денег и возврат карты в пиксельном интерфейсе.
5. **Чек операции:** показ или сохранение краткого чека с суммой операции
    и остатком на счёте.
6. **Дополнительно, после согласования:** смена PIN, перевод между учебными
    счетами и режим обслуживания для пополнения кассет банкомата.

## Запуск начального прототипа

Из корня репозитория, macOS:

```sh
cmake -S coursework -B coursework/build
cmake --build coursework/build
./coursework/build/atm_simulator
```

В начальном меню: `1` — вставить учебную карту, `0` — закрыть программу.
После вставки ввести PIN `1234` или `c`, чтобы вернуть карту.
После входа доступны команды:

- `1` — баланс;
- `2` — внесение: количество купюр по 100, 500 и 1000 рублей, затем подтверждение;
- `3` — снятие: сумма и подтверждение, после успеха выводится набор купюр;
- `4` — история операций;
- `5` — остатки купюр в кассетах;
- `0` — вернуть карту и завершить сеанс (программа возвращается в начальное меню).

Windows, PowerShell, при установленном Visual Studio 2022 с C++:

```powershell
cmake -S coursework -B coursework/build_windows -G "Visual Studio 17 2022" -A x64
cmake --build coursework/build_windows --config Debug
.\coursework\build_windows\Debug\atm_simulator.exe
```


```sh
cmake -S coursework -B coursework/build -DBUILD_ATM_MOCKUP=ON
cmake --build coursework/build
./coursework/build/atm_mockup
```

На другом компьютере предварительно нужна SDL2 с CMake-конфигурацией.
При `BUILD_ATM_MOCKUP=OFF` консольная программа собирается без SDL2.

## Проверка

Тесты с fixture Google Test проверяют операции, отмену, историю, доступ
по карте, PIN, переполнение, недостаток наличных и подбор купюр.
Для первой сборки нужен установленный Google Test или интернет.

```sh
cmake -S coursework -B coursework/build -DBUILD_TESTS=ON
cmake --build coursework/build
ctest --test-dir coursework/build --output-on-failure
```
