ПЯТАЯ ЛАБОРАТОРНАЯ: СБОРКА, ЗАПУСК И ТЕСТЫ

Все команды выполняются из папки 5dz, где находится этот commands.txt.
В ней должны быть две папки: 1-4 и 5.
Сначала открой терминал в этой папке, затем выбери нужный блок команд.

Нужен CMake и компилятор C++17.
При первой сборке с тестами нужен интернет для загрузки Google Test,
если он не установлен локально.

==================== macOS ====================

Терминал: Terminal (zsh или bash).
Компилятор: Apple Clang из Xcode Command Line Tools.
Если инструменты разработчика ещё не установлены:

xcode-select --install

--- Часть 1-4: без тестов ---

cmake -S 1-4 -B 1-4/build_macos -DBUILD_TESTS=OFF
cmake --build 1-4/build_macos
./1-4/build_macos/app/program

--- Часть 1-4: с тестами ---

cmake -S 1-4 -B 1-4/build_macos_tests -DBUILD_TESTS=ON
cmake --build 1-4/build_macos_tests
./1-4/build_macos_tests/app/program
ctest --test-dir 1-4/build_macos_tests --output-on-failure

--- Часть 5: без тестов ---

cmake -S 5 -B 5/build_macos -DBUILD_TESTS=OFF
cmake --build 5/build_macos
./5/build_macos/app/program

--- Часть 5: с тестами ---

cmake -S 5 -B 5/build_macos_tests -DBUILD_TESTS=ON
cmake --build 5/build_macos_tests
./5/build_macos_tests/app/program
ctest --test-dir 5/build_macos_tests --output-on-failure

==================== Windows ====================

Терминал: PowerShell.
Команды ниже используют Visual Studio 2022 или Build Tools 2022
с установленными средствами разработки классических приложений на C++.
CMake должен быть доступен в терминале.

--- Часть 1-4: без тестов ---

cmake -S 1-4 -B 1-4/build_windows -G "Visual Studio 17 2022" -A x64 -DBUILD_TESTS=OFF
cmake --build 1-4/build_windows --config Debug
.\1-4\build_windows\app\Debug\program.exe

--- Часть 1-4: с тестами ---

cmake -S 1-4 -B 1-4/build_windows_tests -G "Visual Studio 17 2022" -A x64 -DBUILD_TESTS=ON
cmake --build 1-4/build_windows_tests --config Debug
.\1-4\build_windows_tests\app\Debug\program.exe
ctest --test-dir 1-4/build_windows_tests -C Debug --output-on-failure

--- Часть 5: без тестов ---

cmake -S 5 -B 5/build_windows -G "Visual Studio 17 2022" -A x64 -DBUILD_TESTS=OFF
cmake --build 5/build_windows --config Debug
.\5\build_windows\app\Debug\program.exe

--- Часть 5: с тестами ---

cmake -S 5 -B 5/build_windows_tests -G "Visual Studio 17 2022" -A x64 -DBUILD_TESTS=ON
cmake --build 5/build_windows_tests --config Debug
.\5\build_windows_tests\app\Debug\program.exe
ctest --test-dir 5/build_windows_tests -C Debug --output-on-failure

==================== Примечания ====================

После изменения C++-кода повтори команду cmake --build из выбранного блока.
Для повторного запуска без изменений достаточно команды запуска программы.

В Windows используется Debug: поэтому путь содержит app\Debug\program.exe,
а для CTest указано -C Debug.

Демонстрационные тесты FailureDemo намеренно отключены в исходном коде.
Сообщение Disabled для них ожидаемо.

Для Git нужны исходники, CMakeLists.txt и этот commands.txt.
Созданные папки build_macos, build_macos_tests, build_windows,
build_windows_tests и другие папки сборки добавлять в коммит не нужно.
