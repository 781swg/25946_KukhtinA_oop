# Работа 10 — 06.11.2026 (часть)

Реализована начальная часть задания:

- Обычный, нешаблонный `Robot`, без дружественных функций и классов.
- `CargoRobot` с публичным наследованием от `Robot`.
- Приватная масса груза `weight`, допустимый диапазон от 0 до 50 кг.
- Конструкторы пустого и загруженного грузового робота.
- Публичный `show_weight()` для вывода массы.
- В `main.cpp` показаны пустой робот, груз 20 кг, предел 50 кг и перегруз.

Осталось реализовать наследника грузового робота с автономным режимом:
`final`, приватное наследование, случайный выбор сообщения о режиме 50/50
и публичную доступность `show_weight()` у этого наследника.

Из корня репозитория:

```sh
cmake -S classwork/06-11-2026 -B classwork/06-11-2026/build
cmake --build classwork/06-11-2026/build
./classwork/06-11-2026/build/program
```
