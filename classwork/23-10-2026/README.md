# Работа 8 — 23.10.2026

Самостоятельная версия класса `Robot` с копированием и перемещением.
В `main.cpp` отдельно показаны все четыре операции.

- Копирование сохраняет состояние источника.
- Конструктор перемещения передаёт строки через `swap`, без копирования их
  содержимого. Источник получает имя `Robot`, команду `stand`, заряд 100
  и нулевые дистанции, поэтому остаётся пригодным для использования.
- Присваивание с перемещением обменивает состояния: источник получает
  прежние параметры получателя. Это допустимый вариант перемещения.
- Новый объект всегда получает новый id. Присваивание сохраняет оба id.
- `std::move` разрешает выбрать перемещающую перегрузку; сам он данные
  не перемещает. Числа и `std::array<double, 10>` не владеют отдельной
  динамической памятью, поэтому для них перемещение не даёт выигрыша.
- Конструктор перемещения не объявлен `noexcept`: создание нового строкового
  id и строк для исходного состояния может потребовать выделения памяти.

В `tests/test_robot.cpp` используется Google Test fixture `RobotTest`:
`SetUp` создаёт робота перед каждым тестом, `TearDown` удаляет его и проверяет
счётчик. Проверяются копирование, перемещение, id, самоприсваивание,
повторное использование источника и недопустимые значения.

Из корня репозитория:

```sh
cmake -S classwork/23-10-2026 -B classwork/23-10-2026/build
cmake --build classwork/23-10-2026/build
./classwork/23-10-2026/build/program
ctest --test-dir classwork/23-10-2026/build --output-on-failure
```

При первой сборке тестов нужен установленный Google Test или интернет
для его загрузки. Для сборки только программы добавь `-DBUILD_TESTS=OFF`
к первой команде.
