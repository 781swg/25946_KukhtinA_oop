# Классные работы 6 и 7

Обе работы реализуют класс квадропедального робота `Robot` на C++17.
Каждая папка — самостоятельный проект.

## 09-10-2026 — работа 6

Все поля приватные: уникальный id, имя, заряд, команда, дистанция за сегодня
и массив дистанций за последние 10 дней.
Есть конструкторы по умолчанию, инициализации и копирования, оператор
присваивания и деструктор. Их вызовы выводятся в консоль.
Пустое имя, заряд вне диапазона 0–100 и отрицательные дистанции запрещены.
История передаётся в порядке от самого давнего дня к последнему.

Id создаётся автоматически и не бывает пустым. При копировании новый объект
получает новый id. При присваивании id получателя сохраняется.

## 16-10-2026 — работа 7

К предыдущей версии добавлены геттеры и статические поля:

- `objectCount` — количество существующих объектов;
- `nextId` — счётчик для создания уникальных id, не уменьшается при удалении;
- `className` — общее имя класса.

Конструкторы увеличивают `objectCount`, деструктор уменьшает его.
Присваивание не создаёт объект, поэтому количество не меняется.
Все сообщения содержат текущее количество объектов.

`const` используется для id и имени класса, потому что они не меняются.
Геттеры, проверка данных и печать отмечены `const`, потому что не изменяют
объект. Строки и массив возвращаются по константной ссылке: без копирования
и без возможности изменить приватные данные. Параметры таких типов тоже
принимаются по константной ссылке. Для `nextId` геттер не нужен: это внутренняя
деталь генерации id. У статических методов нет `this`, поэтому после них
не ставится `const`.

## Сборка и запуск

Команды выполняются в терминале из корня репозитория:

```sh
cmake -S classwork/09-10-2026 -B classwork/09-10-2026/build
cmake --build classwork/09-10-2026/build
./classwork/09-10-2026/build/program

cmake -S classwork/16-10-2026 -B classwork/16-10-2026/build
cmake --build classwork/16-10-2026/build
./classwork/16-10-2026/build/program
```
