# Работа 7 — пояснение const

- `const std::string id` запрещает менять идентификатор после создания
  робота. Новый объект получает новый id; присваивание сохраняет id получателя.
- `static const std::string className` хранит общее неизменяемое имя класса.
- `const` после геттеров, `validate()` и `printInfo()` означает, что метод
  не изменяет состояние робота. Их можно вызывать у константного объекта.
- `const std::string&` и `const std::array<double, 10>&` в параметрах позволяют
  передавать данные без копирования и запрещают изменять их через параметр.
- Геттеры строк и массива возвращают константные ссылки: данные не копируются,
  но вызывающий код не может изменить приватные поля через эти ссылки.
- Числа геттеры возвращают по значению, поэтому добавлять `const` к их
  возвращаемому типу не нужно.
- `objectCount` и `nextId` не константные: они изменяются при создании
  и уничтожении объектов. Остальные поля состояния могут меняться при
  присваивании, поэтому также не объявлены `const`.
- Статические методы не имеют `this`, поэтому `const` после них не ставится.
